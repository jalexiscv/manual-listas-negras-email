# Capítulo 15: Glosario de Términos

[← Anterior](14-estudios-de-caso.md) | [Índice](README.md) | [Apéndices →](apendice-a-dnsbl-comparativa.md)

---

## A

| Término | Definición |
|---------|------------|
| **Alignment** | En DMARC, condición donde el From: coincide con el dominio autenticado |
| **ARC** | Authenticated Received Chain — preserva autenticación en reenvíos |
| **ASN** | Autonomous System Number — identifica una red |

## B

| Término | Definición |
|---------|------------|
| **Backscatter** | NDRs enviados a direcciones falsas |
| **BIMI** | Brand Indicators for Message Identification — logo junto al correo |
| **Bounce** | Rebote: Hard (permanente) / Soft (temporal) |

## C

| Término | Definición |
|---------|------------|
| **CAN-SPAM** | Ley estadounidense de correo comercial |
| **CASL** | Canadian Anti-Spam Legislation |
| **CIDR** | Notación de rangos de IP |

## D

| Término | Definición |
|---------|------------|
| **DBL** | Domain Block List — lista de dominios |
| **DKIM** | DomainKeys Identified Mail — firma digital |
| **DMARC** | Política que unifica SPF y DKIM |
| **DNSBL** | DNS-based Blackhole List |
| **Double Opt-In** | Suscripción con confirmación por email |

## F

| Término | Definición |
|---------|------------|
| **FBL** | Feedback Loop — notifica reportes de spam al remitente |
| **FQDN** | Fully Qualified Domain Name |
| **False Positive** | Falso positivo — correo legítimo marcado como spam |

## G

| Término | Definición |
|---------|------------|
| **GDPR** | Regulación europea de protección de datos |
| **Greylisting** | Rechazo temporal de correos desconocidos |

## H

| Término | Definición |
|---------|------------|
| **Honeypot** | Dirección falsa para detectar spammers |
| **Hard Bounce** | Rebote permanente |

## L

| Término | Definición |
|---------|------------|
| **LGPD** | Lei Geral de Proteção de Dados (Brasil) |
| **Listwashing** | Práctica ilegal de verificar direcciones compradas |

## M

| Término | Definición |
|---------|------------|
| **MTA** | Mail Transfer Agent (Postfix, Exim, Sendmail) |
| **MSA** | Mail Submission Agent (puerto 587) |
| **MUA** | Mail User Agent (Outlook, Thunderbird) |
| **MX** | Mail Exchange — registro DNS del servidor de correo |

## O

| Término | Definición |
|---------|------------|
| **Open Relay** | Servidor SMTP sin autenticación — peligroso |
| **Opt-In** | Permiso explícito del usuario |

## P

| Término | Definición |
|---------|------------|
| **PBL** | Policy Block List (Spamhaus) |
| **PTR** | Pointer Record — DNS inverso |
| **Phishing** | Suplantación para obtener información sensible |

## Q

| Término | Definición |
|---------|------------|
| **Queue** | Cola de correos pendientes |
| **Quarantine** | Cuarentena — correo marcado como spam |

## R

| Término | Definición |
|---------|------------|
| **RBL** | Realtime Blackhole List |
| **rDNS** | Reverse DNS |
| **Rate Limiting** | Limitación de tasa de envío |

## S

| Término | Definición |
|---------|------------|
| **SBL** | Spamhaus Block List |
| **SMTP** | Simple Mail Transfer Protocol |
| **SNDS** | Smart Network Data Services (Microsoft) |
| **SPF** | Sender Policy Framework |
| **Snowshoe Spam** | Muchas IPs, bajo volumen cada una |

## T

| Término | Definición |
|---------|------------|
| **TLS** | Transport Layer Security |
| **TTL** | Time To Live |
| **Transactional Email** | Facturas, confirmaciones, recovery |

## W

| Término | Definición |
|---------|------------|
| **Warm-up** | Aumento gradual de volumen de envío |
| **Whitelist** | Lista blanca |

## X

| Término | Definición |
|---------|------------|
| **XBL** | Exploits Block List (Spamhaus) |

## Z

| Término | Definición |
|---------|------------|
| **Zen** | Lista compuesta de Spamhaus (SBL + XBL + PBL) |
